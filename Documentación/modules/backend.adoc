== Anexo — Backend (`backend/`)

Muestra representativa dado el volumen del código (441 archivos `.py`, 70 archivos de casos de uso, excluyendo `+__init__.py+`, 22 `handler.py`). El análisis es representativo. Las rutas y roles se contrastan con los handlers citados y su registro en `infra/stacks/api_stack.py`; los comentarios de cabecera por sí solos no demuestran autorización.

=== Capa compartida (`backend/shared/`)

* `shared/db/base_repository.py` — repositorio base (ver cita completa en sección 7 del documento principal).
* `shared/db/client.py`, `db/transactions.py`, `db/paginator.py` (cursores opacos base64 para paginación), `db/counts.py` (`paginated_count`, usado por `_count_raw`), `db/locks.py` (locks transaccionales de unicidad, p.ej. RUC de tenant, SKU de producto, identificación de cliente — patrón mencionado explícitamente en los comentarios de `database_stack.py`, líneas 39-40, 140-141, 163).
* `shared/audit/writer.py` — construye el ítem de auditoría (`audit_item`) consumido por `BaseRepository._audit` (`base_repository.py:183-206`).
* `shared/certificates/` — `validator.py` (validación `.p12`, ver sección 6), `store.py` (persistencia en Secrets Manager), `metadata.py`, `expiry.py`, `errors.py`.
* `shared/secrets/client.py` — `get_secret_json`, usado por `auth`, `subscriptions`, `tenants` para leer credenciales de dLocal Go sin exponerlas como variables de entorno con valor literal.
* `shared/domain/events/` — `outbox.py`, `publisher.py` (`EventPublisher`, `DirectPublishReason`), `domain_event.py` (ver `modules/evidencia.adoc`).
* `shared/domain/base_entity.py` — `TenantScopedEntity`, tipo base referenciado por `BaseRepository._to_item`/`_from_item` (abstractos, `base_repository.py:210-216`).
* `shared/domain/value_objects/` — incluye `ruc.py` (value object `RUC`, usado en `CertificateValidator.validate_bytes`, `validator.py:54`, para normalizar y comparar el RUC del certificado contra el del tenant).
* `shared/logger.py` — logging estructurado; `bind_invocation_context`/`clear_invocation_context` consumidos por `_base/handler.py` y `_base/sqs_handler.py`.
* `shared/errors.py` — jerarquía `AppError` (`NotFoundError`, `ForbiddenError`, `ValidationError`, `OptimisticLockError`, `DatabaseError`, `ExternalServiceError`, `IdempotencyInProgressError`, `IdempotencyKeyReusedError`, entre otras) mapeada a códigos HTTP por `ApiResponse.error` (`_base/response.py`).
* `shared/billing.py` — cálculo de precios (`gross_price`, `plan_net_price`), usado por `subscriptions` y por `workers/subscription_renewal_notifier/use_case.py:210`.
* `shared/dates.py` — `isoformat_ecuador`, `now_utc` (normalización horaria a la zona de Ecuador para fechas visibles al usuario/SRI).

=== Capa transversal de Lambda (`backend/lambdas/_base/`)

`handler.py` (decoradores HTTP), `sqs_handler.py` (decorador para colas), `permissions.py` (`require_superadmin`, `require_role`), `idempotency.py` (ver `modules/evidencia.adoc`), `parser.py` (`Request.from_event`, `parse`, `require_path_param`), `response.py` (`ApiResponse` — envelope uniforme `{success, data, error}`), `query_params.py` (`parse_enum_query_param`, `parse_list_limit`).

=== Tests (`backend/tests/`)

77 archivos `test_*.py` bajo `backend/tests/unit/lambdas/<dominio>/` (un subdirectorio por cada uno de los 10 dominios HTTP más `invoice_processor`, `_base` y `workers`) y `backend/tests/unit/shared/`. Configuración de cobertura en `backend/pyproject.toml`: `fail_under = 70`, fuente `lambdas,shared`, excluye `.venv`, `tests`, `migrations`. No se ejecutó la suite como parte de esta documentación (fuera de alcance: solo lectura del worktree); el conteo de archivos de test es evidencia directa de que **todos** los dominios HTTP tienen al menos un test unitario, no evidencia del resultado de ejecutarlos.
